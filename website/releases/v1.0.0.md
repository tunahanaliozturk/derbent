The first release. Derbent is a local gate between coding agents and their tools: Claude Code, Codex,
GitHub Copilot CLI and Antigravity CLI connect to it as one MCP server, with your other MCP servers
behind it.

## What's in it

- **Shared memory.** `memory_write`, `memory_search` and `memory_read`, kept per project and shared by
  its worktrees.
- **Your MCP servers behind the gate.** Stdio and HTTP servers, namespaced tools, secrets passed through
  `${env:...}` references, restarts with backoff.
- **Rules.** First-match allow, deny and ask rules by agent, tool and argument. A denied tool is not
  listed to that agent.
- **Approvals.** Held calls wait in the terminal UI or for `derbent approve` from any shell, and are
  denied after the timeout.
- **Receipts.** A hash-chained receipt for every call, with secrets masked; `derbent verify` checks the
  chain.
- **Built-in tools.** `derbent gate` as a pre-tool hook for all four CLIs, so shell commands and file
  edits pass the same rules. [[coverage: which CLIs were checked in real sessions]]

## Overhead

[[p50]] ms per call at p50 and [[p99]] ms at p99 through the gate with an allow rule, on Windows and
Linux.

## Known limits

Read [Security and limits](/docs/security) before relying on Derbent: it guards against mistakes and
against prompt injection that stays inside MCP, not against an agent that already has a shell as you.
